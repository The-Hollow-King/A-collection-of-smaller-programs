# A-collection-of-smaller-programs
This is a collection of my smaller projects

1) Election_eligibilty :
   Created to accept the user's age in a variable named 'user_age' and to print whether the user is eligible to vote or not. Also coded to print 'Invalid age' if the user inputs an absurd number. Didn't made an arrangement     if the user inputs a character instead but the user is instructed to only input numbers (integers specifically)
2) Greatest_Number :
   Three variables are initialized to accept values from the user and to store them. Then the variables are compared with each other, the greatest number is obtained and then the output is given to the user. Not much           prospects of improving this program
3) Simple_interest_calculator :
   Accepts principal amount, rate, time period (in years), calculate the simple interest, in a variable called si and prints the amount of simple interest the user would be paying.
4) Employee_Salary_Calculator :
   Accepts the users name, salary and according to their basic salary, calculates their dearness allowance, house rent allowance, travel allowance, net salary payment, provident fund and gross salary at last and displays       the specific values
